# Práctica de Spring Boot — MVC

Aplicación de la materia de desarrollo de la Universidad Anáhuac Mayab: alta y consulta de productos y usuarios desde el navegador.

## Qué tiene

Controladores MVC para `Index`, `Product` y `Usuario`, entidades JPA con sus repositorios, una capa de servicio entre el controlador y los datos, y vistas en Thymeleaf con fragmentos reutilizables.

## Stack

Java · Spring Boot · Spring Data JPA · Thymeleaf · Maven

> Esta es la versión sólo con MVC. La que además expone una API REST está en `DEMOSPMEDINANOVELO`.
